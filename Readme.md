# Yogi Decoration

Website resmi Yogi Decoration — menyediakan jasa dekorasi untuk berbagai acara seperti pernikahan, ulang tahun, dan event lainnya.

## Fitur
- Katalog produk/jasa dekorasi
- Galeri foto hasil kerja
- Informasi kontak & pemesanan

## Teknologi yang Digunakan
- HTML, CSS, JavaScript

## Cara Menjalankan
1. Clone repository ini
2. Buka file `index.html` di browser
